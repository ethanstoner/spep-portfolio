# SPEP Portfolio

Senior Portfolio Exit Project — a single-page portfolio site.

## Preview locally

```bash
npx serve .
```

Or open `index.html` directly in a browser.

## Deploy

Auto-deploys on push to `main` via Vercel (git-connected).

## Sections

- Home — name, intro, meta
- Scholarship — research project slides
- Integrity — essay with extended analogy
- Reflection — graduation speech
- P.I.T — Passion / Involvement / Teamwork video
